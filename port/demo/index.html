SOURCE PORT / WASM32

Boktai 3, rendered from C.

Run the portable C renderer in your browser. Open local scanline captures to replay game scenes, or select your ROM to execute the original early boot C. Files stay on this device.

Working: compiled C rendering, memory map, early boot and frame timing. Full gameplay boot is still in development. Capture replay supplies recorded hardware state; it does not run the game's main loop.

Runs RTC initialization and date synchronization, clock-state clearing, the IWRAM copy and DMA video initialization. The initial forced-blank frame is white. This check does not enter gameplay.

Build: python port/demo/build_demo.py --hardware-root PATH/port --ppu-root PATH/port. The generated build/demo/index.html also embeds the code module for offline use. No ROM or captured graphics are included in the source page.
