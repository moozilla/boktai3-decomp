Files stay on your computer. This page contains no ROM, game images or captured memory. It replays the graphics subsystem; it does not run the game’s main loop.

How to try it

Open this HTML file directly; no server is required. Choose one or more .ppu.gz or .ppu captures from build/ppu/. Include the matching .ppm files in the same selection to compare pixel for pixel. Reference names must match capture names. For animation, select the numbered files in build/demo/motion/.

Regenerate the bundled module with build/venv/bin/python port/demo/build.py. See port/README.md for capture commands. The screenshot comparison uses mGBA’s RGB888 presentation arithmetic.
