What is running

Portable C sample interpolation, looping, volume and envelopes, plus pulse, wave and noise synthesis. A small test sequencer reads the ROM's songs. The full game is not running on this page.

What has been checked

Native sanitizer and wasm tests pass. A controlled comparison with the original ROM mixer agrees on sample phase and count, with PCM within one 8-bit unit. Song playback omits LFO, memory/extended commands and PSG notes; the counter reports skips.

No ROM, BIOS, game samples or extracted assets are included. The oscillator demo needs no game data. Open this page directly from disk; no server is required.
