61000 and 61080 classify item/consumable moves. For an inventory source (saved selection 0..15), a different destination with at least one occupied endpoint is actionable only in mode 1, returning 1. For a special source, selecting it again moves the cursor to the cached destination and returns 4. Selecting an empty ordinary slot also returns 4. All other paths return 0. The consumable version indexes signed table160 entries in the game-state block.

61120/611AC/6122C classify equipment, item and consumable actions. Catalog selections use index `(page*8 - 16) + selection`; negative catalog entries are invalid. A purchase returns +1 when the signed funds field at game-state+7B0 covers the base value and destination is nonnegative. Ordinary inventory removal returns -1 when each category's validity predicates pass; otherwise the result is zero. Equipment preserves the extra kind query even though its return is unused. Consumable removal also rejects the auxiliary slot predicate and a zero signed definition value at +8. Names of funds/base value are tentative economic interpretations supported by these comparisons and adjacent value-display consumers. The equipment path retains a redundant comparison of a sign-extended byte with 255, as observed.
