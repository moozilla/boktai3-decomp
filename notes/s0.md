## Round 2 tricks
- Unused-looking leading copies (`adds r2,r0; adds r3,r1` at entry) can just come from using struct-typed params and `if (b->t == 0) {...} else b->t--;`; write it straightforwardly (080187E4).
- Stack locals: frame size is a quick check; `CpuSet(&a, b, 0x05000002)` needs `u32 b[2]` for the right frame (0801A3C0).
- Hoist mask constant before first memory op with `u32 m = 0xFFFF0000;` (0801A470).
- Constructors with an `if (G != 0) return G;` guard compile from the plain template; no-guard variant (08013CF4 template vs 08006144) differs only by that guard.
- Param used by `strh`/`strb` only but compared as u8: declare `u32 m` and compare `(u8)m` (08013E88). A u16 callee param with raw u32 caller param: declare caller u32 and callee u16 (08016674).
- Batch build: build/fin.sh (in worktree, gitignored) copies all matching wip files, runs one build.py, then commits each.

## Tricks
- Tiny setters whose asm starts `adds r2,r0,#0` or uses r2/r3 where r0 is free (08037490, 08009500, 080341B0, 08032CC8): declare the function returning `u32` and fall off the end (r0 stays live). Conversely, if mine gets an extra `adds rN,r0,#0` copy (0803CC78, 0803BAF4), the original is void.
- Store of 0 to global then return: `return gG = 0;` with u32 return (08020C28, 08048514).
- Reading s16 into a u8 store keeps ldrsh only if routed through `s32 v = g->a; p->b = v;` (08032C6C).
- Fn-pointer literal before offset constant: `void *f = fn; p->fn = f;` (080050AC). `u32 m = 1; p->a |= m;` hoists const (0802C8A0).
- `if (b == 0) return -1; return f(a,b);` vs result-variable gives the call-first layout (08004194).
- BITFIELDS: stack structs with (w&0xFFFF0000)|v / (w&0xFFFF)|(v<<16) patterns are 'struct { u32 a:16; u32 b:16; u32 c:16; }' with a.field = expr (08008A00).
