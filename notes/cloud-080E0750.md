Patterns that fixed allocation here (all plain C):

* Load first, then mask: `u16 value = actor->flags2D4; u16 test = value & mask;`. A pointer
  to the field (`flags = &actor->flags2D4`) assigned *after* that load reproduces the ROM's
  `adds rN, rM, #0` copy of the address register.
* Or-masks with the value loaded first: `u32 value = *field; mask = 4; mask |= value;`.
* An inline helper returning a local (`s32 r; if (...) r = ...; else r = ...; return r;`)
  gives the extra copy where the ROM moves the result into the variable.
* Note: an unmatched WIP file in src/ skews the baseline ELF once `make` runs, and every
  later symbol shifts. check.py and the permuter then compare against wrong call targets. Keep WIP
  files out of src/ when rebuilding.
