## Tricks
- Functions that already have a real name in gen (Script_*, Text_*, ...) must be defined under that name in the C file (file stays sub_ADDR.c), else split.py fails with 'index out of range'.
- Functions that already have a real name in gen (Script_*, Text_LookupString, ...) must be defined under that name (file stays sub_ADDR.c), else split.py dies with IndexError.
- Unused/extra leading params matter: a binary search `(key, tbl, x_unused, lo, hi)` has hi on the stack (sub_0821A454).
- `u32 *p = tbl_base + (idx<<2)`-style address: `(T *)((idx << 3) + (u32)tbl)` fixes `adds` operand order; for struct-array globals use `struct E *t = gArr; e = t + idx;` with correct element size (pad fields) to get ldr-before-lsls (sub_08221338, sub_0821ACDC, sub_0821ADD4).
- `s32 d = a - b;` as a separate temp before the use flips load order / avoids extra regs (sub_0821B1B8, sub_0821B1DC).
- `ret = c ? X : 0` ternary gives `bhs`-to-zero layout where if/else-with-var gave blo (sub_0821E748); `if (x) return call(); return d;` vs `if (!x) return d;` flips call/return placement (sub_0821ABA8).
- Loop-invariant reload: `if (i < a->fc->n) { s32 n = a->fc->n; do {...} while (i < n); }` gives `ldrb r0; cmp; ... adds r3,r0` (sub_0821E158).
- Callee arg count: a 3rd register arg live from an earlier load (`ldr r2,[r4,#8]` before `bl`) means the callee takes 3 params; load it inside the condition `(sz = t->size) == 0` (sub_0822241C/082224C0).
- Mask hoisting: `u32 k = n->key; u32 m = 0; if (k == key) m = 1; if (m) ...` fixes ldr/movs order (sub_082224C0).

## Tricks (round 3)
- Pointer into struct via two steps: `p = (u32 *)base; p += 0x72c/4;` plus block-local `u32 m` in each branch gives `ldr r2,[r0]; ldr r0,=off; adds r2,r2,r0` with p in r2 (sub_08211960/082119AC).
- Function that falls off the end of a non-void function after calling a value-returning callee returns the callee's r0 (sub_08212D64: declare callee u32, no return).
- Linked-list insert/remove templates (sub_08214374/082143A0/082143CC/082143F8/08214424) match with plain struct N {prev,next}; see wip generator idea: insert sets idx,flag=1,prev=0,next=head,head->prev=n,head=n; remove: p=prev,q=next,flag=0,if(p)p->next=q else tbl[i]=q; if(q)q->prev=p.
- Load-order fix: take the byte field into a local BEFORE `s = &global` (`c = g.f4; s = &g;`) to get ldrb via the first literal and a second literal load for the pointer (sub_08223534); declare `u16 **t = tbl;` before `i = s->f10` to force literal-before-ldrb (sub_08224880).
- Shared-tail stores: `if(p&&p->f4){g.f8=..;g.fa=..;return;} g.f8=0;g.fa=0;` after an if/else gets cross-jumped into the orig shape (sub_08225DA0); for 'extra arg is previous result' pass the result var as arg 1 in the else-branch.
- `z = 0` local + pointers assigned in reverse order (c,b,a) to match literal-pool/register order for stm loops (sub_082142DC).
- `x = m | g` with `u32 m = 0x100;` hoists the constant before the ldrh (sub_0822502C).
- Early `if (f()==0) return -1;` produced orig's beq-to--1 layout for sub_08225590; if(!r){ret=-1}else{..} did not.
