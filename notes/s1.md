# s1 notes

## Tricks
- `if (a || b) r = 0; else r = 1; return r;` reproduces "bne ret0; call; beq ret1; ret0: movs 0; b end" layouts (0804EB38); plain `&&`/early returns do not.
- Declare the constant local first (`u32 m = 1;`) before pointer init to get `movs r3,#1` before the pointer setup in a loop (0804D874).
- Nested `if (a) { if (b) return 1; } return 0;` matched where `&&` into a result var did not (0804EA38).
- Switch with cases 2 and 3 sharing a body but compiled as separate `cmp #2; beq; cmp #3; beq`: write two separate `case 2:` / `case 3:` blocks with identical bodies (cross-jump merges them); `case 2: case 3:` gives a `bgt` range test instead (08064918, 08064954).
- Wrapper ending `pop {r1}; bx r1` that just forwards args: make caller and callee `s32` and `return callee(...)`; extra stack args are just more params (08066A88, 08066AB4, 080684D0).
- Function that stores `r = callee(); *(u16*)... = r;` and has epilogue `pop {r1}` with `adds r2,r0,#0` copy: declare `u32 r = 0;` return type u32, fall off the end (08061CA8).
- Big-offset object accessors match with plain `u8 *p` + `*(T *)(p + off)` casts when no arrays are indexed; most were first-try.
- Local copy of a ROM table: `struct T { u32 a,b,c; }; extern const struct T gUnk_...; struct T t = gUnk_...;` gives ldm/stm (080638BC).
- Table-search loops: `s32 i = 0;` at decl (movs before the ldr), and `p++, i++` order controls adds order (08060528).

## Skips
- 0804EBD8: Div(v*x,0x8c) with v ternary from ptr; target copies v to r2 (`adds r2,r0; muls r2,r1,r2; adds r0,r2`), all variants (u32/s32/u16, v*=x, x*=v) give `muls r0,r1,r0`.
- 0804E730: `if (f&0x20) r=2; else r=(f&0x10)!=0;` target uses `rsbs r0,r1; lsrs r1,r0,#31` in else branch and branches before loading 2; mine speculates `movs r1,#2` before cmp. 3 variants.
- 0804EAFC: loop over i<p->n with q=p+i*0xa8 (flag at +0xc9, call with +0x34). Target keeps p in r4/i in r5 and mul via `adds r1,r5,#0; muls r1,r0,r1`; mine swaps r4/r5 and muls into r0. ~8 variants incl. struct-less casts.
- 0804EED0 (twin of 0804EAFC): real struct (u8 n at 0x26, struct E e[] at 0x34 size 0xa8 w/ flag at +0x95) fixes the r4/r5 and mul registers, only remaining diff is call arg: target 'adds r0,r1,r4; adds r0,#0x34' vs mine 'adds r0,r1,#0; adds r0,r4,r0; ...' (extra mov). ~6 variants.
- Operand order of an indexed load (adds r0,r0,r1 vs adds r1,r1,r0): write `*(s32 *)((u8 *)tbl + (i << 2))` instead of tbl[i] (08056F20).
- If the target keeps an unexplained copy of a pointer in r1 (`adds r1,r0,#0`) across a call, the callee takes extra (leftover) args: declare it with them and pass p, p->a (08055BA8).
- 08055DA0: loop matches, but epilogue `movs r1,#0; ldr r0,=gUnk; str r1,[r0]; movs r0,#0` (store 0 and return 0 NOT merged) vs agbcc merging into one zero. tried u32/void*/volatile. same shape as the 'return *p = 0' tip but without merging.
- 08059264, 080592AC: timer++ then `if (t >= p->max) {call(p->h); p->x=0; p->t=0}` with zero in r6 (callee-saved) set between the add and the strh; agbcc orders movs r6 before the ldrh or inserts the u16 truncation (lsls/lsrs) before the strh. 5 variants (z decl position, u16 n temp).

## Round 2 skips
- 0806147C: u16 at +0x1AEC loaded, stored u8 to +0x1BE7; (v&3)+4 -> +0x1BE5; (+0x1BE7)>>2 -> +0x1BE6. Target loads ldrh into r2 with addr in r1, mask const in r1 (movs r1,#3; ands r1,r2); mine reuses r1 for the load and puts mask in r2. 4 variants (u16/u32 v, struct, re-reading p->a).
- 08065BEC: alloc-slot loop (mask u32 at +0xA1C, 8 elems stride 0x138 at +0x5c, idx byte at +0x99; returns elem or 0). Target keeps const 1 in r7, &mask in r3, two pointers r4/r5 stepped by r6=0x138, bit test as unoptimized bool (`beq; movs 1; b; movs 0; cmp; bne`) with `1<<i` recomputed. 5 variants (struct array, u8* ptrs, inline tst helper, ternary, `one` local): mine always puts the stride in ip/r7 and loop var in r5.
- 08065C40: 'bl f; cmp r0,#0; bne; movs r0,#0' (return f(); but with explicit zero on null) is folded away by agbcc in all forms tried (if r==0 r=0; ternary).

## Round 3 skips
- bit-allocator loops (mask test as unoptimized bool `beq; movs 1; b; movs 0; cmp; bne`): 0806F400, 0806A788, 0806BC8C, 0806F3A8 (same family as 08065BEC). Ternary/!!/if-else/inline helper/vu32 all fold the bool or change regs (vu32 gives `rsbs;orrs;bge`).
- 0806DFB8: `r=f(); if(r==0) r=0; return r` (cmp; bne; movs r0,#0) folded away (same as 08065C40).
- 0806A694: two nested flag tests `movs r0,#4; ands r0,r2` / `movs r0,#0x80;lsls;ands r0,r2` (dest r0, v kept in r2); mine gives `ands r2,r0`. tried &&, nested, inline tst, u16 v, mask-first.
