# s4 notes

## Tricks
- Loops over array of structs: `for (i=15;i>=0;i--) { ...; e++; }` with e++ inside body (not in for-increment) gives `adds r4,#stride` before `subs r5,#1`.
- Global ptr cached in reg + new value in same reg (`str r0,[r4]; adds r4,r0,#0`): write `gX = f(); r = gX;` (no local pointer-to-global).
- Local const array copy from ROM (`ldm/stm`): `struct T { u32 a[3]; }; struct T t = gROM;` then index t.a[i].

- `switch(x){case 1:..;case 2: case 3:..}` matches `cmp 1;bne;cmp 1;blt;cmp 3;bgt` (if-chain with ranges folds to unsigned sub instead).

- `m=4; if ((m & g)==0)` after a store gives `movs r1,#4` before the `ldr r0,=g`. A `u32 m=4;` at top of function hoists it before everything (matches `movs r2,#4` first).

- u16 field `&= ~4` gives a literal-pool 0xfffb; orig `movs r0,#5; rsbs r0,r0,#0` before the ldrh = declare field `s16` and use `s32 m = ~4; f &= m;`.
- Orig `ldr r1,=func` BEFORE the big-offset address constant: use `void (*f)(void) = fn; p->cb = f;`.

## Tricks
- `x |= C` where orig emits `movs r0,#C; ... ldr r2,=g; ldrh r1,[r2]; orrs r0,r1; strh r0,[r2]` (constant first): `u32 m = 0x100; gX = m | gX;`.

## Tricks
- THE sub_0802DCD8 "state handler" family (about 40 functions in 081C6B..081CC1: `if (p->b9) { b9=0; b7=0; switch (p->b1) {26-entry table 4..29, one value} sub_0802DCD8(p, r, A, B, S); } tail`) matches with a generated template (wip/swgen2.py, not committed). KEY: when the lone special case value is near the end or at idx 0/1, a plain `case 4:..case 29: r=0; ... case N: r=V; default:` makes agbcc emit `cmp; bne` instead of the table; SPLIT the "others" into two case-lists with identical bodies (`case 4..15: r=0; break; case 16..29(except N): r=0; break; case N: r=V; break; default: r=0; break;`) to get the table. Middle values (idx 23) worked without splitting.
- Zero shared by `strb r0,[p+0x18]; str r0,[p+0x10]` with a single `movs r0,#0`: `{ u32 z = 0; B(0x18) = z; W(0x10) = z; }`; `p->x = (p->y = 0)` does NOT share it.
- A callee that gets r3 = a global value loaded early (`ldr r3,[g]; cmp r3,#0; beq` then the call with 0,0,fn in r0-r2) means the callee takes a 4th arg: pass the global as 4th param (081C1E00).
- Struct array loops `for (i=N-1;i>=0;i--){ e->fl |= m; e++; }` with `struct E{u32 fl; u8 pad[stride-4];}` and `u32 m=1`/`u32 m=~1` declared BEFORE `struct E *e = p->e;` match the `push{lr}; movs r3,#1; movs r2,#off>>k; adds r1,r0,r2; ...` pattern (081C0C58, 1A58, 1A78, 1C6C, 1CEC, 1D0C).
- `gU16 = gU16 & 0xFFFFF0FF` with orig order `ldr r2,=g; ldr r0,=mask; ldrh r1,[r2]; ands`: `u16 *g = &G; u32 m = 0xFFFFF0FF; *g = *g & m;` (081C0608; probably fixes 081C6224).
- `h |= 0x1000` with the constant built before the ldrh: `{ u32 m = 0x1000; p->h = m | p->h; }`. For `h += 0x100` with `movs r3,#0x80; lsls; adds r1,r3,#0; ldrh r3; adds`: `*h = (u16)(0x100 + *h);` (081C847C).
- agbcc pads sizeof(struct) up to a multiple of 4 even for u16-only structs: account for it when padding with `u8 g[N]` after a nested struct.
- 20/32-byte struct copy from the return value of a callee (`ldm/stm` 3+3+2 words) = `struct Q{u32 a[8];}; p->q = *callee();` (081C1510).
- `if (p->v > p->c) return 10; if (p->v > p->b) return 5; if (p->v > p->a) return 2; return 1;` with u16 fields at 0x58a..: no local copy of p->v (orig re-derives addresses); an `if (v<=a) return 1` form flips bls/bhi.
- `if (g) return g; p = f(); ... g = p` creators (`081C4BC4`) match with plain C; `p = g = f();` matches the `str r0,[r4]; adds r4,r0,#0` pattern (081C2FC0).
