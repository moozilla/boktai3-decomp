# s4 notes

## Tricks
- Loops over array of structs: `for (i=15;i>=0;i--) { ...; e++; }` with e++ inside body (not in for-increment) gives `adds r4,#stride` before `subs r5,#1`.
- Global ptr cached in reg + new value in same reg (`str r0,[r4]; adds r4,r0,#0`): write `gX = f(); r = gX;` (no local pointer-to-global).
- Local const array copy from ROM (`ldm/stm`): `struct T { u32 a[3]; }; struct T t = gROM;` then index t.a[i].

- `switch(x){case 1:..;case 2: case 3:..}` matches `cmp 1;bne;cmp 1;blt;cmp 3;bgt` (if-chain with ranges folds to unsigned sub instead).

- `m=4; if ((m & g)==0)` after a store gives `movs r1,#4` before the `ldr r0,=g`. A `u32 m=4;` at top of function hoists it before everything (matches `movs r2,#4` first).

- u16 field `&= ~4` gives a literal-pool 0xfffb; orig `movs r0,#5; rsbs r0,r0,#0` before the ldrh = declare field `s16` and use `s32 m = ~4; f &= m;`.
- Orig `ldr r1,=func` BEFORE the big-offset address constant: use `void (*f)(void) = fn; p->cb = f;`.

## Tricks
- `x |= C` where orig emits `movs r0,#C; ... ldr r2,=g; ldrh r1,[r2]; orrs r0,r1; strh r0,[r2]` (constant first): `u32 m = 0x100; gX = m | gX;`.
- Several literals/field values loaded into regs BEFORE a set of stores (e.g. `movs r0,#0xaf; lsls; movs r1,#0xc4; movs r5,#0; strh..`): put values in locals `s16 a=..., b=...; s32 z=0;` declared in order, then store them; pass z for later 0 args too (`p->f = z`).
- Orig does `adds r0,p,#K` BEFORE `movs r4,#0` for `p->x = 0; call(...,0)`: write `p->x = (z = 0);`.
- Function pointer stored late (after a call / other stores) with literal loaded just before the store: `void (*f)(void); ...; f = fn; p->cb = f;`. Declared-and-initialised at top hoists the literal to the front. Thumb-bit-labelled data target (`.4byte 0x081C5121` to a trailing data label): cast `(void (*)(void))0x081C5121`.
- `if (x==0) r=0; else {...; r=1;} return r;` gives orig's `bne else; movs r0,#0; b end` layout (vs `if (x) {...}` which gives beq).
- Bit-nibble helpers: hoist `h = i/2; odd = i&1;` into locals before other temps to match instruction order; `u32 k=0xf` local shared as mask and `c &= k`.
- Tail-ptr store sequence `adds r0,#4; ...; subs r0,#0x20` (three stores to p+0xf4,+0xf8,+0xd8): plain struct fields in order f4, f8, d8 match.
- worklist JUMPTABLE flags on 081C50E0 also a false positive (plain function, followed by raw data).
- 081C6224: `gU16 = (gU16 & 0xF0FF-ish mask) | 0x400` (u16 global at 0x03004BD8) then a 7-arg call with &local: orig order `ldr r2,=g; ldr r0,=0xFFFFF0FF; ldrh r1,[r2]; ands; movs r1,#0x80; lsls; orrs`; ours loads ldrh before mask or hoists mask above r2, and puts 0x400 in r3 with an extra `adds r1,r3,#0`; also the second `movs r0,#1` (arg0) vs shared-const reuse differs.
- 081C674C: (a,b)->{b->h0e=0;b->b7=0;b->f10++; if(b->f2cc) f(a,b); return 0}. Orig keeps a in r5, an unused copy of old f10 in r2, and f2cc in r4 (3 pushes); ours drops the dead temps (1 push). Dead-value locals (old=b->f10++, cb=...) are optimised away.
- Unused `u32 buf[4];` local reserves stack (`sub sp,#0x10` with no stores): matches funcs that have an unused sp frame (081CD46C).
- Large local ROM-array copy (>3 words) makes agbcc call memcpy (unresolved); orig calls sub_0824DA48(buf, rom, size): declare `s32 t[40]; sub_0824DA48(t, gROM, 0xa0);` and use `if (n<=0x27) r=t[n]; else r=-1;` (081CE060/08C/0B8).
- 081D1A44: `s=b->b1b; b->b65=s; b->b1a=((s+0x70)>>5)&7; b->b19=((s+0x60)>>6)&3; call` right in all fields; orig puts s in r2 and temps in r1/r0 (r1 still live), ours s in r1, temps r0/r1 (one reg off). Tried operand swap, s32/u32.
- Bottom-tested countdown loop where orig does `subs r5,#1` BEFORE `adds r4,#stride`: put the pointer step in the for-increment: `for (i=39;i>=0;i--, e+=0x48)` (vs body-step for the opposite order).
- `if (g) return g;` (re-reading the global) reuses the loaded reg as the return value (orig `bne end` with r0 = loaded global) -- matches 081D35CC.
- Real switches (round 2): 081C5EA8 (cases 1..5 -> consts, default -1), 081EA78C (0,4,5 / 1,2,3 grouped), 081D3F24 (42-entry table, sparse cases 0x3e..0x67) all MATCH with a plain C `switch` + result var + single return, tables included. Only trick: write the case groups in the order the arm bodies appear in the asm (agbcc emits arms in source order). `.4byte _08...` table with `ldr; mov pc` is the reliable signature. 081E28D4 (flagged JUMPTABLE) is a false positive (plain fn + trailing data).
