# NamedObject_CreateFromScript

All 1,856 bytes match with stock agbcc. The final player and tether flag writes
use a halfword mask and the named object's flags field. This gives both writes
the same implicit halfword zero, which survives between them in r7. Reading
the follow option in a statement block keeps the option itself in r5.

The constructor steps the shared player-cue sequence and passes the route
cursor, world position and signed X/Z limits to its final proximity check.
