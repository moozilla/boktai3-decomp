# s2 notes (range 080C9844-0813B134)

## Tricks
- `x &= ~2` style RMW where orig loads the constant BEFORE the ldr: `u32 *p=&s->f; u32 m=~2; *p = *p & m;` (also for `u16 *p` with `u32 m=0xFFFFEBFF`).
- Mask-before-address ordering for `if(!(s->h & 0x40))`: declare `u32 m = 0x40;` after loading other pointers, then `s->h & m`; if the mask must come after a call, assign it after the call (`u32 m; call(); m = 0x2000;`).
- Pointer-store functions (`movs r1,#0xa2; lsls; adds; ldr; str`): `struct S { u8 filler[0x284]; const u8 *p; }`; several stores at stride 8 -> array of `struct {const u8 *a; u32 pad;}`.
- Counter-with-rollover functions (sub_080F49BC, sub_080F2480) match with `u32 *c=&s->cnt; if((*c&3)==0) s->a += s->b; *c = *c-1; ...` using plain struct fields.
- `if (x) return 1; fp = f; return 0;` where orig branches to the 'else' with beq: use `s32 r; if(x) r=1; else {...; r=0;} return r;`.
- worklist's JUMPTABLE flag is spurious when the function is followed by undecoded .byte data (sub_080CC8B8, sub_080E41D4, sub_080E4458 were not switches). Real ones (e.g. 08100A64, 0811C77C, 080FD128) not tried.
- Tooling: tools/build.py and check.py share build/, don't run them in parallel (readelf errors).

## Tricks (round 2)
- RMW with const BEFORE address calc: `u32 m=K; u32 *p=&s->f; *p=*p|m;`. Const after address but before ldr: `p=&q->f; m=~0x11; *p=*p&m;` (separate statements). Plain `s->f |= K` puts the ldr first.
- To force `movs rN,#0` between an `ands` and its `strh`: `hv = *hp & hm; zero = 0; *hp = hv;` with `u16 zero;` declared uninitialised.
- Accessing a byte at 0xdc+0xf as `adds r2,#0xdc; ldrb [r2,#0xf]`: nested struct `struct B {u8 pad[0xf]; u8 b;}` at 0xdc, `t=&s->bb; t->b = t->b & bm`.
- 080FB8E8: 16-iter loop storing 0/0x1f/0x7c00/0x7fff into 3 u16 arrays + copy from src; orig hoists only 0 (r7) and 0x7fff (r6), keeps 0x1f/0x7c00 as in-loop movs, counts r5 up to 0xf; mine hoists all four and counts down (index and pointer-increment variants).
- 080FBEDC: loop over 4 entries, `if(*t){ if(--*t==0) e->f |= 1;}`; layout correct but gcc hoists the `movs r,#1` out of the loop (r5) while orig keeps `movs r1,#1` after the ldr inside the branch.
- 080FF7AC: `return (s->h & m) ? 1 : 0` (orig: push lr, and/cmp/bne, movs 0/1 branches) -- same unthreaded-bool class as 080F9374; I emit the rsbs/orrs/lsrs trick instead.
- Class "unthreaded bool": 080FFFE4, 080FF820, 0810033C, 0810038C (all `r = (cond) ? 1:0; if(r)` with merge block `movs 1; b; movs 0; cmp r0,#0` and a literal pool dumped mid-function). Tried: if/else r, ternary, static inline returning 1/0, inline returning `!= 0`, local `f=(..)!=0`. agbcc always threads or gives rsbs/orrs. Not solved; skip all of these.
- 0810103C: do{ e=*pp; if(e&&k==*gp) e->p = (u16)(h-3)<=1 ? e+0x284 : 0; pp++;}while(--i>=0) with i=0 start; all structure right but gcc hoists the 0x284 constant (movs;lsls -> mov ip) out of the loop; orig materialises in-branch.
- Switch functions (08100A64, 0811C77C) matched with plain C `switch`; for 08100A64 the fall-through case order is `case 3: if(!(f&0x20)) goto b; case 0: A; break; b: case 1: case 2: case 4: B; break; default: B;` (case bodies ordered by asm address, not value).
- Generated functions: ~35 "singleton task create" functions (`if(g) return g; p=alloc(a,sz); if(p){reg(p,cb1,cb2); if(init(p)<0){free(p);return 0;}} return p;`, e.g. 08100068, 08104EB0) all match from a template; scripts were kept in build/s2 (gen2.py). Variants taking extra args (08108FB4, 0811EE9C...) not done.
- Pointer-returning search loop: `r=a; goto end;` inside do-while + `r=0; end: return r;` reproduces `bne` loop-continue layout (08101A74).
- Loads of four fields before two subtractions: declare locals px,bx,py,by in that order then dy, dx (08100F28).

## Tricks (round 3)
- Regenerated gen/ exposes many clone families; clustering functions by normalised asm (numbers -> #N, symbols -> F) in a script finds them in seconds (wip/cluster.py idea: key = tuple of normalised lines). Then one regex-based C generator per family + `check.py` per file + copy on MATCH matched 86 functions this round with almost no manual work.
- `void f(void){}` matches the bare `bx lr` callbacks (15 of them).
- `gUnk = 0;` stubs: `ldr r1,=A; movs r0,#0; str r0,[r1]; bx lr`; `s32 f(u32 a){ gUnk = a; return 0; }` for `str r0,[r1]; movs r0,#0`.
- Zeroed-alloc template: `p=sub_08219C40(N); if(p){ sub_08219DD8(p,N); if(init(p)<0){fin(p); sub_08219D38(p);} }` (void, push r4,r5).
- Table index after call: `i = f(); p = gUnk_array[i];` as two statements keeps the table literal load after the call (a one-liner hoists it).
- Loop ending `movs r0,#0; str r0,[r1]; pop {r1}`: `return gUnk = 0;` with s32 return.
- Tooling: build/s2 scripts are not in the worktree; recreated under wip/ (ignored).
