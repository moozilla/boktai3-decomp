# s3 notes

## Tricks
- Assigning a constant to a local before the use (`m = 0xFFFF0000; x = (x & m) | 1;`) moves the constant load ahead of the memory load (0813B374).
- Offset-in-big-struct leaf (`ldr r2,=0x41A; adds r0,r0,r2`): struct with `u8 filler[0x41A]; u16 v;`. A mask param that is not truncated is `u32`, not `u16` (0813B134).
- `a || b || c` single return expression gives the "return 1 first, return 0 at the end" layout where nested ifs give the opposite (0813B318 layout).
- `*(s16 *)((u8 *)g + g->idx * 2 + 0x88)` gives add-index-first ordering that array syntax does not (0813B3E8).

## Tricks
- Round 2: families of init/state-setter functions (0815AEE0..0815C3F0) all match with one shared local `struct P` (padded with `u8 fNN[]` fillers, fields only where used); keep the struct text in a scratch header and paste it into each file.
- A callee whose return value is passed through (`pop {r1}; bx r1` with the call result still in r0, e.g. 081604C0) is `return`-less: write the call as a statement and fall off the end of an `s32` function (no `r` variable).
- Success/failure alloc pattern (`r=alloc(); if (r) { setup(r); if (init(r)<0) { free(r); return 0; } } return r;`) matches 0816033C/081605DC/081626E0/08162BA0 only with `return 0;` inside the inner if (not `r = 0`).
- `struct P *q = p;` extra copy used for a later call arg reproduces `adds r1,r0 / adds r3,r1` double-copy at function entry (08162D58).
- Declaring `u32 v = *c;` before `u32 r = 0x1f;` flips the ldrb/movs order (0816381C).
- Global pointer reloaded after stores (list-insert 0815F6A8/F6F0): declare it `struct L *volatile` and read it once into a local for the first use; later uses through the global reload. Combine with andm/orm inline helpers to put the mask const before the ldr.
- `andm(&g1, ~4)` for the first of two RMW ops (mask derived from an earlier `movs r1,#1`) and plain `g2 &= ~1` for the second reproduces the shared-r1 constants (0815FF40).
- Callee's declared arg count matters: a call with only 2 args needs an unprototyped `void f();` locally (0815BFB8).
- tools/check.py links against the last full build's ELF: after a failed/mismatching full build, callee addresses can be stale and every `bl` shows as a diff. Fix the build first.
