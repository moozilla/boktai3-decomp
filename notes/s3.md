# s3 notes

## Tricks
- Assigning a constant to a local before the use (`m = 0xFFFF0000; x = (x & m) | 1;`) moves the constant load ahead of the memory load (0813B374).
- Offset-in-big-struct leaf (`ldr r2,=0x41A; adds r0,r0,r2`): struct with `u8 filler[0x41A]; u16 v;`. A mask param that is not truncated is `u32`, not `u16` (0813B134).
- `a || b || c` single return expression gives the "return 1 first, return 0 at the end" layout where nested ifs give the opposite (0813B318 layout).
- `*(s16 *)((u8 *)g + g->idx * 2 + 0x88)` gives add-index-first ordering that array syntax does not (0813B3E8).

## Skips
- 0813B480: if-chain on (f&1),(f&4),(f&8),(f&0x10),(f&0x20) -> r=5/10/0 then call sub_0813B418(p,r). Plain || merges 4|8|0x10 into 0x1c; goto form keeps them separate and f lands in r1 as original, but 'movs r1,#0' (r=0) is emitted before 'movs r0,#0x20' instead of after the ands, and the post-call 'adds r1,r0,#0' copy is absent. ~8 attempts.
- 0813BA24: p+0x744 (u32 buf, str of call result) and q=p+0x748 (sub-struct passed to 3 calls, |=1 at +0, bytes at +0xF=1,+0x10=0x14), p[0x770]=p[0x771]=0. Original keeps call result in r1, const 0x744 in r0 then 'adds r0,#4' to derive 0x748. Mine either loads 0x748 separately (struct form) or puts const in r4 and result in r0 (o+=4 form). ~6 attempts.
- 0813C000: two switches (a&3: cases 1,0,2 -> value itself else 1 [signed tree: beq 1; bgt; beq 0; beq 2]; then a: <=2 ->0, 3..4 ->2, 5 ->3, else 1). agbcc range-folds contiguous cases to 'cmp #2; bhi', or emits jump table; could not reproduce the compare tree. 3 attempts.
- 0813DB60: u16 counter at +0xAD4 decrement, if (cnt!=0 && ((cnt-1)>>2 &1)) return p->u16@0xAD2 else d. Original copies p->r3 then d->r2 (mine swaps: p r2, d r3); '||' form gives the right branch layout but pushes r4 / swaps regs. ~8 attempts.
- 0813F784: table select (flag 0x1000 of gUnk_030053F4 -> 08610940 else 0861091C) then t[i] u16. agbcc loads both literal addrs before the branch (ternary or if/else); original loads one per arm and shares lsl/add. 3 attempts.
- TRICK: `static inline u32 tst(u32 *a, u32 m) { return *a & m; }` then `tst(&p->flags, 0x1000)` gives address-calc, mask const, then ldr, ands (const loaded BEFORE the ldr). Plain `p->flags & 0x1000` loads the const after the ldr. (0813F7B4)
