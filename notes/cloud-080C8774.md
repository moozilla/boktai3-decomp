## sub_080CF3E4 (Golem_ArriveAndRestore), draft at 80.5%

The draft is in src/fn/sub_080CF3E4.c (task 080E0750 raised it from 77.2%). The later fixes:
Chase_TryRoute and the turn's group, flags2D4 and 0x414 tests take the caller's `obj` (not the
copied `actor`); flag tests load first, then mask; the turn loop is
`for (tries = 0; tries <= 3; tries++)` with a u8 choice. Earlier notes: The function is a short prologue
followed by `Chase_Arrive` from include/scene_actor_chase.h, so it validates that header
inline. Two corrections are already in the attempt's local copy:

* The ROM has one `Callback_InvokeActor(group + 0x224)` at the end, shared by the
  missing-partner path and the reroute failure (header: two copies).
* In the ROM, the stores after the random-direction choice in `Chase_BeginTurn` have their
  addresses hoisted before the loop. Writing them inside the loop
  (`for (;;) { ...; if (choice == prior) { if (++tries <= 3) continue; choice = prior; }
  stores; break; }`) reproduces the hoisting. A `table` local in the random helper also
  helps (127 structural differences instead of 176). Both versions are still 75-77% because
  of allocation: the ROM keeps `&actor->flags2D4` live from the first 0x80 test (sp+0x20).
