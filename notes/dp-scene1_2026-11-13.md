## Concession-free functions

* SceneObjects_ScriptLower (0801E998): typed pool/slot fields, a byte-returning variant
  helper, and mask declaration order remove two pins and a memory barrier. The helper
  changes the variant's first-pass loop lifetime from 2 to 3, hoisting one ahead of the
  mask. Earlier diagnostic `AGBCC_PRI=35:+20,44:-20` matched the allocation-only draft.
  All 216 bytes match. Search store: `build/matchsearch/SceneObjects_ScriptLower`.
* ScenePool_StateLaunchArc (0803E5F4): a common case-two clear call with per-arm history
  expressions and one shared clear local, selector reuse in case zero, and separate
  default/branch returns remove all three pins and four barriers (one table pin was
  submitted separately first). All 448 bytes match. The last allocation was confirmed
  by `AGBCC_FORCE=148:1`; sharing clear across the arms avoids the three-qty sort bug.
* ScenePool_StateLaunchShortArc (0803E7B4): the same tail on the prior ordinary-C front
  matches all 484 bytes; two pins and four barriers removed.
* ScenePool_StateEmitBursts (0803E998): the same tail, retaining the existing captured
  kind address for the final read, matches all 604 bytes; three pins and four barriers
  removed. Reading the field directly adds a PRE copy in the burst front half.

* ContactSwarm_UpdateTracking (08044290): duplicate the collider call and frame read
  in both phase arms. CSE stops reusing 15 across calls; jump2 merges both tails. The
  call alone does not merge because its fallthrough has flow's `(use 0)`. 236 bytes.
* ActorAttachment_CreateValueSpriteSlot (08065FD0): the prior helper/goto draft had
  15 PRE spill-offset differences. Duplicate flag update in both offset arms (+4
  pre-GCSE insns) and priority store in both mode arms (+3). T becomes 133 and the
  spills match; both tails merge later. All 680 bytes, no concessions.
* ActorAttachment_CreateSinglePartSlot (08066278): move existing frame narrowing
  before pointer declarations, duplicate the flag update and share its one with the
  later byte store. Explicitly read flags before setting one. Delay part pointer
  assignment until after the geometry zeros. The existing SDK CpuFill32 macro supplies
  the original fill-source stack slot. All 508 bytes; 51 explicit concessions removed.
