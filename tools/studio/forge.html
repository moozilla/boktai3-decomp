How builds and experiments work

Forge compiles the whole source unit with its existing compiler settings, links it at the original address, and compares the resolved bytes with your ROM. Click an annotated instruction to jump to its C line. The compiler pass shows where agbcc first created it; the explanation follows differences through later decisions.

Playable builds currently use a fixed layout: code must fit the unit's original span, preserve public function addresses, and use text-section storage. Edits that need relocation can still be compiled and inspected. Text edits use existing string space. Each job exports one unit and its text edits; experiments are independent.

A screenshot demonstrates that the game ran; it does not establish that the edited function was reached. No ROM downloads are served. IPS and C files are exported from the exact compiled snapshot.
